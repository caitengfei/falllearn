# 防跌学堂（FallLearn）

**智慧健康养老 · 岗课赛证融通 学生学习平台**

面向「智慧健康养老服务与管理」专业学生，围绕技能点 **「老年人跌倒的预防与应急处置」**，把**岗**（国家职业技能标准）、**课**（课程标准/教案/实训任务单）、**赛**（世界职业院校技能大赛 + 山东省"技能兴鲁"赛项规程与评分标准）、**证**（养老护理员 / 健康照护师 / 老年人能力评估师等级证书考核标准）四个维度的真实材料融进一套可学习、可练习、可考核、可管理的在线平台。

> 参赛说明：本仓库为自包含交付（代码 + 题库种子 + 知识库 + 自动化测试）。演示账号均为虚构代号，不含真实学生个人信息。

## 一、30 秒跑起来

环境要求：**Python 3.10+**（本机验证环境 3.12）、Node.js 18+（仅前端二次开发时需要；仓库已含构建产物 `frontend/dist`）。

```bash
# 1) 后端（首次启动自动建库：题库 1350+ 题、6 知识簇、3 演示学生 + 1 教师）
pip install -r backend/requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8010 --app-dir backend

# 2) 打开浏览器
# 学生端   http://<本机IP>:8010/        （学生一键登录：S2026001 / 123456）
# 管理后台 http://<本机IP>:8010/admin   （教师登录：T2026 / 123456）
```

> 前端 dist 已构建完成，**评委无需 Node 环境**：uvicorn 单端口直接同时服务 API 与页面（GZip 已开启）。
> 二次开发前端才需要：`cd frontend && pnpm install && pnpm build`。

### AI 功能（可选但推荐演示）

AI 问答 / AI 出题 / AI 判卷 / 知识库检索 依赖本机 **DSH（DeepSeek Harness）智能体服务**：

1. 把本仓库 `knowledge/` 目录作为 DSH 会话工作区（26 份岗课赛证 Markdown 文档）；
2. 在 DSH 中使用预设 `gksc-student`（智能体提示词见 `knowledge/05-元数据/智能体提示词模板.md`）；
3. 后端 `aiops.py` 通过 DSH HTTP 接口（端口 3080）接入，模型可在「管理后台 → AI 管理 → 模型选择」中切换（本地 qwen 网关 / DeepSeek / FreeHub 免费渠道 GLM、DeepSeek、SenseNova）。

无 DSH 环境时平台其余功能（学习、练习、考试、错题本、积分、管理端）完全可用，AI 入口会明确提示「AI 服务未连接」。

## 三、技术架构

```
Vue 3.5 + vue-router 4 + Vite 6（frontend，构建产物 frontend/dist）
        │
FastAPI + SQLite（backend/app，单端口 8010 同时服务 API 与静态页，GZip）
        │
DSH 智能体服务（可选，端口 3080）← knowledge/ 26 份岗课赛证文档（工作区）
        │
题库种子 backend/seed/questions_seed.json（1353 题，6 知识簇；AI 生成的题可在管理后台持续入库扩充）
```

- **一致性设计**：知识簇 id/名称/颜色/题量前后端共享（`/api/meta/clusters` 实时下发，前端静态回退）；六簇 = Morse评估 / 环境防控 / 五步处置 / 骨折识别 / 记录上报 / CPR启动。
- **工程质量**：
  - `tools/` 内含 5 套自动化验收脚本（学生端全流程 e2e、管理端 e2e、管理 API、AI 链路、修复项逐项验收）——`python tools/e2e_platform.py` 一条命令回归全链路（含真实 AI 问答）；
  - `docs/expert-admin/` 保留 QA/UX/视觉/内容/性能五专家审核报告（72 项 finding 全量修复闭环记录）；
  - 数据库 8 个热列索引、N+1 查询全部批量化、AI 任务 30s 硬超时 + 判卷幂等（`ai_grades.attempt_id` UNIQUE）。
