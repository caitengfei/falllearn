## 核心内容摘要

本教案对应《老年人安全照护与急救技术》项目二"跌倒的防护与急救"任务3"跌倒的应急处置"，2 学时（90 分钟）理实一体课。以"夜班护理员发现老人跌倒"真实情境为主线，完成风险评估—不动评估—呼救—分级处置—记录上报全流程教学，考核对齐赛项评分细则与证书实操考核点。

### 二、学情分析

1. **知识基础**：二年级学生已完成任务 1（Morse 量表）与任务 2（环境排查）学习，具备风险评估基础；但"先扶起来"的错误直觉普遍存在（前测中预计 50% 以上学生第一反应是扶人），认知冲突是本课切入点。
2. **技能水平**：已完成单人 Morse 评估与清单排查，尚未做过多人协作的应急处置全流程；呼救话术、记录单填写为首次系统训练。
3. **学习特点**：高职学生偏好情景化、游戏化与同伴互评；对"大赛扣分点"与"考证考点"的关联敏感，备课时应明示考核同源性。
4. **差异化**：对实操基础较弱的学生，示范环节增加"慢动作分解"；对基础好的学生，组内指派"记录员/点评员"角色。

### 三、教学目标

1. **知识**：说出跌倒现场处置"五步法"（评估意识与伤情→不急于搬动→呼叫支援→按预案处置→记录上报）及每一步的依据。
2. **技能**：能对跌倒老人完成意识/呼吸/疼痛部位评估；能识别疑似骨折并正确就地制动；能规范填写跌倒事件记录单。
3. **素养**：做到"先评估、后搬动"的安全底线意识；操作中全程人文关怀（安抚、隐私保护）；培养"不隐瞒、及时报"的职业习惯。

### 四、教学重点与难点

- **重点**：跌倒应急处置五步法的顺序与操作细节（评估内容、呼救话术、疑似骨折制动、记录要素）。
- **难点**：①"不急于搬动"的决策判断（老人要求起身/疼痛主诉/环境危险时的取舍）；②疑似骨折与可起身情况的现场鉴别。

### 五、教学过程（90 分钟）

**环节1 情境导入（10 min）**
- 播放/讲述真实案例："22:40，护理员夜间巡视发现 3 床王奶奶坐在床边地上，主诉'膝盖疼'。"
- 提问：第一反应该做什么？能不能先扶起来？（引发"先扶起来"的错误直觉，制造认知冲突）
- 明确学习目标与考核要求（出示评分表，说明与大赛/证书考核同源）。

**环节2 前测与衔接（10 min，BOPPPS 之 O→P 前测）**
- 随堂前测 5 题（3 分钟，口头或纸质）：①Morse 量表总分与高危切点；②近 3 个月跌倒史计几分；③跌倒后第一步做什么；④疑似髋部骨折能扶吗；⑤记录单必须包含哪三项。
- 依据前测结果动态调整：错误集中点（常见为③④）在环节 3 重点强化；已掌握点（常见为①②）从快。
- 衔接回顾：任务 1（Morse 量表）与任务 2（环境排查）要点——预防做在前面，处置才有意义，引出"评估—报告—防控—处置"闭环。

**环节3 新课讲授：五步法（20 min）**
1. 评估意识与伤情：ABC（气道-呼吸-循环）快速判断 → 意识（呼唤应答）→ 疼痛主诉与部位 → 关键部位视触诊（头/髋/四肢）。
2. 不急于搬动：任何疑似骨折/头部撞击/意识改变，就地制动；解释骨折端移位的危害。
3. 呼叫支援：呼叫同事/按应急预案分级呼叫（意识不清或大出血/疑似心肺骤停 → 立即呼叫并启动急救，含心肺复苏启动条件）。
4. 按预案处置：保暖、安慰、体位调整（在评估前提下）、疑似骨折就地固定、拨打 120 指征。
5. 记录上报：跌倒事件记录单要素（时间、地点、情境、伤情、处置、报告人、报告时间、后续跟踪）。
- 每步穿插"为什么"（对应岗位标准条款与扣分点，标注来源 01-岗/、03-赛/ 文档）。

**环节4 教师示范（10 min）**
- 双人示范完整流程：A 饰演老人（按脚本主诉"右髋疼痛、无法站立"），B 饰演护理员。
- 示范要点：沟通话术（"王奶奶，我先看看您哪里不舒服，请不要动，我马上叫同事"）、节力姿势、隐私遮挡。

**环节5 分组实训（25 min）**
- 4 组轮换：①疑似髋部骨折（制动+呼救+记录）②老人要求起身（评估后协助/拒绝的决策）③意识不清（启动急救流程）。
- 教师巡回纠偏；组内用评分表互评，记录扣分点。

**环节6 总结与考核（15 min）**
- 每组 1 分钟汇报最易错点；教师点评（对照 03-赛/常见扣分点总结.md）。
- 随堂笔试 5 题（五步法顺序、呼救指征、骨折判断、记录要素、一票否决项）。
- 布置课后任务：填写 1 份模拟跌倒事件记录单 + 对照 Morse 量表自评"自己家里老人的跌倒风险"。

### 六、课程思政融入点

- "先评估、后搬动"= 生命至上、规范先行（职业底线）。
- 及时上报、不隐瞒 = 职业诚信与团队安全文化。
- 安抚与隐私保护 = 人文关怀、以老年人为中心。

## 可直接引用的片段

> 跌倒现场处置"五步法"：①评估意识与伤情 → ②不急于搬动 → ③呼叫支援 → ④按预案处置 → ⑤记录上报。

> 重点：跌倒应急处置五步法的顺序与操作细节；难点："不急于搬动"的决策判断与疑似骨折/可起身情况的现场鉴别。

> 一票否决项：未先评估意识直接搬动、延误呼救、对疑似骨折老人随意搬动。
