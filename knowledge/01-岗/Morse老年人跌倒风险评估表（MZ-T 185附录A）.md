# Morse 老年人跌倒风险评估表（MZ/T 185 附录 A）

来源：MZ/T 185—2021《养老机构预防老年人跌倒基本规范》附录A（规范性）
维度：岗
关键词：跌倒、风险评估、Morse量表、养老机构、评估频次

## 核心内容摘要

Morse 老年人跌倒风险评估表用于评估养老机构入住老年人的跌倒风险，总分 0–125 分：0–24 低危、25–45 中危、≥45 高危。标准第 5.2 条明确评估频次：每年至少一次；高危者通知相关第三方带老人做专业评估；发生跌倒、跌倒住院后、病情变化、用药调整时必须复评。

## 一、量表说明

评估得分越高，说明跌倒风险越大。养老机构应在老年人入住时进行跌倒风险评估，并根据评估结果采取预防措施。

**评估频次要求（依据 MZ/T 185—2021 第5.2条）：**
- 养老机构应每年对入住老年人进行不少于一次的跌倒风险评估。
- 对跌倒风险评估为高危风险的老年人应通知相关第三方，由其带老年人进行专业的跌倒风险评估。
- 老年人发生跌倒、跌倒住院后、病情发生变化、用药调整时，应进行一次跌倒风险评估。
- 评估结果应告知相关第三方，并与相关第三方沟通，获得支持。

## 二、评估表

| 项目 | 评分标准 | 得分 |
|---|---|---|
| 近三个月内跌倒史 | 否=0；是=25 | |
| 超过一个医疗诊断 | 否=0；是=15 | |
| 行走是否使用辅助用具 | 不需要/卧床休息/他人协助=0；拐杖/手杖/助行器=15；轮椅、平车=30 | |

| 认知状态 | 自主行为能力=0；无控制能力=15 | |
| **总得分** | | |

## 三、结果评定

| 总得分 | 风险等级 |
|---|---|
| 0—24分 | 低风险 |
| 25—45分 | 中风险 |
| ≥45分 | 高风险 |

## 四、使用说明

1. 本量表为规范性附录，适用于养老机构预防老年人跌倒的管理。
2. 评估得分越高，说明跌倒风险越大。
3. 对评估为高危的老年人应通知相关第三方，由其带老年人进行专业的跌倒风险评估。
4. 评估结果应记录在老年人健康档案或照护记录中，并告知相关第三方。
5. 老年人发生跌倒、跌倒住院后、病情发生变化、用药调整时，应重新进行一次跌倒风险评估。
