# 老年人跌倒后标准处置流程

来源：《老年人跌倒干预技术指南》、MZ/T 185—2021《养老机构预防老年人跌倒基本规范》、WS/T 887—2026《社区老年人跌倒预防控制技术标准》、第二届全国民政行业职业技能大赛养老护理员技术工作文件
维度：岗（岗位标准）+ 课（课程知识）+ 赛（竞赛评分）+ 证（证书考核）通用
关键词：跌倒、应急处置、现场救助、标准处置流程、不要急于扶起

## 核心内容摘要

**核心原则：发现老年人跌倒，不要急于扶起，要分情况进行处理。** 五步流程：①现场评估与初步判断（意识→生命体征→询问观察→保持跌倒后姿势）→②分情况处理（意识不清/意识清楚两条线）→③按伤情分类处置（未受伤/皮下出血/外伤出血/骨折）→④报告与记录（报告医生、记录不漏项、启动应急预案、告知家属）→⑤心理安抚与人文关怀。救助四原则（WS/T 887—2026 第7.6条）：尽早开始、保证安全、合理救护、心理支持。

## 一、核心原则

根据WS/T 887—2026《社区老年人跌倒预防控制技术标准》第7.6条，对跌倒老年人的救助应遵循以下基本原则：

1. **尽早开始**：对跌倒老年人的救助应尽早开始。
2. **保证安全**：确保救助过程中老年人和救助者的人身安全。
3. **合理救护**：根据伤情和现场资源条件实施合理救助。
4. **心理支持**：在救助过程中给予老年人心理安抚和情感支持。

**核心原则：发现老年人跌倒，不要急于扶起，要分情况进行处理。**

## 二、标准处置流程（分步骤）

### 第一步：现场评估与初步判断

**1.1 评估意识状态**
- 轻拍老年人肩部，大声呼唤，判断其意识是否清醒。
- 根据WS/T 887—2026第7.6.3条：先评估意识状况，检查呼吸、循环等基本生命体征。

**1.2 检查生命体征**
- 检查呼吸、脉搏、血压等基本生命体征。
- 必要时测量脉搏、呼吸、血压（依据大赛评分标准M8）。

**1.3 询问与观察**
- 询问老年人跌倒情况及对跌倒过程是否有记忆。
- 询问有无头晕头痛、恶心、呕吐等。
- 观察摔伤部位，疼痛情况，有无出血、畸形、肿胀及功能障碍等。
- 询问是否有剧烈头痛或口角歪斜、言语不利、手脚无力等提示脑卒中的情况。
- 查询有无腰、背部疼痛，双腿活动或感觉异常及大小便失禁等提示腰椎损害情形。

**1.4 保持跌倒后姿势**
- 让老年人保持跌倒后的姿势、减少活动（依据大赛评分标准M8）。
- 不要急于搬动老年人。

### 第二步：分情况处理

根据《老年人跌倒干预技术指南》第四部分"老年人跌倒后的处理"，分以下两种情况进行处理：

#### 情况一：意识不清

**处置要点：立即拨打急救电话。**

1. **有外伤、出血**：立即止血、包扎。
2. **有呕吐**：将头偏向一侧，并清理口、鼻腔呕吐物，保证呼吸通畅。
3. **有抽搐**：移至平整软地面或身体下垫软物，防止碰、擦伤；必要时牙间垫较硬物，防止舌咬伤；不要硬掰抽搐肢体，防止肌肉、骨骼损伤。
4. **如呼吸、心跳停止**：应立即进行胸外心脏按压、口对口人工呼吸等急救措施。
5. **如需搬动**：保证平稳，尽量平卧。

#### 情况二：意识清楚

1. **询问跌倒情况**：询问老年人跌倒情况及对跌倒过程是否有记忆。如不能记起跌倒过程，可能为晕厥或脑血管意外，应立即护送老年人到医院诊治或拨打急救电话。
2. **询问脑卒中症状**：询问是否有剧烈头痛或口角歪斜、言语不利、手脚无力等提示脑卒中的情况。如有，立即扶起老年人可能加重脑出血或脑缺血，使病情加重，应立即拨打急救电话。
3. **处理外伤出血**：有外伤、出血，立即止血、包扎并护送老年人到医院进一步处理。
4. **排查骨折**：查看有无肢体疼痛、畸形、关节异常、肢体位置异常等提示骨折情形。如无相关专业知识，不要随便搬动，以免加重病情，应立即拨打急救电话。
5. **排查腰椎损害**：查询有无腰、背部疼痛，双腿活动或感觉异常及大小便失禁等提示腰椎损害情形。如无相关专业知识，不要随便搬动，以免加重病情，应立即拨打急救电话。
6. **协助缓慢起立**：如老年人试图自行站起，可协助老人缓慢起立，坐、卧休息并观察，确认无碍后方可离开。
7. **如需搬动**：保证平稳，尽量平卧休息。
8. **后续就医**：发生跌倒均应在家庭成员/家庭保健员陪同下到医院诊治，查找跌倒危险因素，评估跌倒风险，制定防止措施及方案。

### 第三步：根据伤情分类处置（依据大赛评分标准M8）

**1. 老年人未受伤**：密切观察老年人身体情况，如意识、生命体征、皮肤等。
**2. 皮下出血、肿胀**：嘱老年人减少活动并予以冰袋冷敷处理。冷敷方法及时间正确，避免发生冻伤。
**3. 外伤出血**：初步评估伤口情况，协助老年人进行外伤出血包扎。包扎方法科学、正确，避免感染。
**4. 骨折**：嘱老年人减少活动，并进行肢体固定。请医生予以指导及处理。

### 第四步：报告与记录

1. **报告医生**：报告医生，遵医嘱给予处理（依据大赛评分标准M8）。
2. **记录**：记录不漏项，包括评估阳性结果、主要措施及异常情况等（依据大赛评分标准M13）。
3. **上报**：能准确启动与执行突发事件应急预案/措施，规范完成急救处置与上报（依据大赛评分标准M11）。
4. **告知家属**：尽早通知老年人家属或其他照护者（依据WS/T 887—2026第7.6.5条）。

### 第五步：心理安抚与人文关怀

1. **心理安抚**：处理过程中密切观察老年人情况，及时给予心理安抚（依据大赛评分标准M8）。
2. **沟通解释**：表达信息方式符合老年人社会文化背景，使用符合老年人认知水平的礼貌用语，语速、音量适配老年人生理特征。
3. **尊重意愿**：充分尊重老年人生活习惯与自主选择，老年人"知情—选择—确认"照护后确认舒适度并落实后续服务衔接。
4. **维护尊严**：维护服务对象隐私与尊严，非必要不暴露身体部位，在无关场景下回避个人信息。

## 三、跌倒后损伤的处理（依据《老年人跌倒干预技术指南》）

### 1. 外伤的处理

- **清创及消毒**：表皮外伤，用双氧水清创，红药水消毒止血。
- **止血及消炎**：根据破裂血管的部位，采取不同的止血方法。
  - **毛细血管**：擦破皮肤，血一般是从皮肤内渗出来的。只需贴上创可贴，便能消炎止血。
  - **静脉**：静脉破裂后，血一般是从皮肤内流出来的。必须用消毒纱布包扎后，服用消炎药。
  - **动脉**：动脉一旦破裂，血是呈喷射状喷出来，必须加压包扎后，急送医院治疗。

### 2. 扭伤及肌肉拉伤

- 要使受伤处制动，可以冷敷减轻疼痛，在承托受伤部位的同时可用绷带结扎紧。

### 3. 骨折

- 骨折部位一般都有疼痛、肿胀、畸形、功能障碍等表现，骨折端刺破大血管时还可能会出现大出血。
- 骨折或疑为骨折时，要避免移动伤者或伤肢，对伤肢加以固定与承托（有出血者要先止血后固定），使伤员在运送过程中不因搬运、颠簸而使断骨刺伤血管、神经，避免额外损伤，加重病情。

### 4. 颈椎损伤

- 跌倒时若头部着地可造成颈椎脱位和骨折，多伴有脊髓损伤、四肢瘫痪。必须在第一时间通知急救中心速来抢救。
- 现场急救时，应让伤者就地平躺或将伤员放置于硬质木板上，颈部两侧放置沙袋，使颈椎处于稳定状态，保持颈椎与胸椎轴线一致，切勿过伸、过屈或旋转。

### 5. 颅脑创伤

- 轻者为脑震荡，一般无颅骨骨折，有轻度头痛头晕，若昏迷也不超过30分钟。
- 重者颅骨骨折可致脑出血、昏迷不醒。对颅脑创伤者，要分秒必争，通知急救中心前来及时救治。要保持安静卧床，保持呼吸道通畅。

## 四、老年人自己如何起身（依据《老年人跌倒干预技术指南》）

如果老年人意识清楚、有能力自行起身，可按以下步骤操作：

1. 如果是背部先着地，应弯曲双腿，挪动臀部到放有毯子或垫子的椅子或床铺旁，然后使自己较舒适地平躺，盖好毯子，保持体温，如可能要向他人寻求帮助。
2. 休息片刻，等体力准备充分后，尽力使自己向椅子的方向翻转身体，使自己变成俯卧位。
3. 双手支撑地面，抬起臀部，弯曲膝关节，然后尽力使自己面向椅子跪立，双手扶住椅面。
4. 以椅子为支撑，尽力站起来。
5. 休息片刻，部分恢复体力后，打电话寻求帮助——最重要的就是报告自己跌倒了。

## 五、关键安全提示

1. **不要急于扶起**：发现老年人跌倒，不要急于扶起，要分情况进行处理。
2. **不盲目搬动**：对于可疑头部外伤、脊柱或下肢骨折的老年人，不可盲目搬动老年人（依据WS/T 887—2026第7.6.4条）。
3. **优先处理威胁生命的损伤**：根据伤情、现场资源条件实施救助。
4. **疑似脑卒中不扶起**：如怀疑脑卒中，立即扶起老年人可能加重脑出血或脑缺血，使病情加重，应立即拨打急救电话。
5. **疑似骨折不搬动**：如无相关专业知识，不要随便搬动，以免加重病情，应立即拨打急救电话。
6. **疑似腰椎损害不搬动**：如无相关专业知识，不要随便搬动，以免加重病情，应立即拨打急救电话。
