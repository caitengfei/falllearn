## 核心内容摘要

本文件提供两道可直接用于校内模拟考核的实操试题：**试题一"为老年人进行跌倒风险评估及应对"**与**试题二"为跌倒的老年人进行急救处理"**（均 12 分钟限时、100 分制，评分骨架为 M1–M13＋J 综合评判）。评分条目以民政部参考赛题库（S12）官方分值为准，江苏题库（S13）十一步骤应急流程作对照校验。智能体出"实操题"时沿用此骨架，改案例背景（机构/居家/社区）即可。

## 详细内容

### 考核形式（官方口径）

- 现场实操/模拟操作；使用**标准化老年人（标准病人/模特）**：任务说明原文"请模拟真实情况，充分与标准化老年人合作，除标明可口述或可假设部分，其他尽可能真实操作"。
- 流程：读题备物（10–12 分钟）→ 限时操作（12 分钟）→ 记录整理。
- 通用规则：每遗漏一项关键物品扣 0.5 分直至扣完；违反法规标准言行该项零分；提前结束示意后不得再操作。

### 试题一：为老年人进行跌倒风险评估及应对（12 分钟，100 分）

**案例（模板，可替换）**：养老机构 3 床，张爷爷，78 岁，2 型糖尿病＋高血压，近 3 个月曾在卫生间跌倒 1 次，现使用手杖行走，长期口服多种药物。请对其进行跌倒风险评估并制定应对措施。

**评分表（官方分值，S12 原文拆项）**

| 板块 | 评分条目 | 分值 |
|---|---|---|
| 职业规范/准备 | M1 简述识别老人跌倒风险的初步情况并做出正确应对（2 分）＋M2 着装、手卫生、用物（Morse 量表、评估记录单、笔等）齐全、环境准备（4 分） | 6（漏关键物品扣 0.5/项） |
| 沟通解释评估 | 问好称呼、核实身份（两种方式）、综合评估、介绍评估目的与配合要点、询问是否可以开始 | 15 |
| **M8 关键操作** | （1）跌倒风险评估：①及时发现跌倒风险，确保老年人处于安全状态；②**依据 Morse 跌倒风险评估量表进行跌倒风险评估**；③评估结果准确 | 12 |
| | 告知老年人跌倒的风险及预防跌倒的意义 | 4 |
| | 与老年人共同分析导致跌倒的风险因素（**环境、生理、疾病、药物、心理、其他**等） | 10 |
| | 根据风险因素采取科学有效、针对性强、老年人易接受的应对措施，**措施不少于 3 条**：①创造安全的环境（家具、地面、扶手、灯光等）；②合理用药；③合理使用辅助器具；④调整生活方式；⑤**智慧产品的使用（穿戴跌倒预警手环、防跌倒背心等）** | 20 |
| | 反馈老年人掌握情况，持续关注预防跌倒措施的落实情况 | 4 |
| 健康教育 | 主题合适、每主题≥3 条、准确有效、结合个体情况 | 5 |
| 科技照护 | 智能监测数据解读、安全预警处理、管理平台记录 | 5 |
| 安全防护 M11 | 风险识别与处置、节力与伤害预防、安全防护沟通、应急预案与上报 | 5 |
| 人文关怀 | 共情、沟通适配、知情-选择-确认、隐私尊严 | 5 |
| 记录 | 评估阳性结果、主要措施、异常情况**不漏项**；手卫生 | 5 |
| J 综合评判 | 灵活机动、服务态度与亲和力、职业素养与责任心 | 4（+ 红线：违反法规标准零分） |

**本案例参考判读（整理推断，供评分参考）**：Morse 得分＝跌倒史（25）＋继发诊断（15）＋手杖（15）＝55 分 → 高危（≥45）；风险因素：近 3 个月跌倒史、糖尿病（低血糖风险）、多种药物（体位性低血压）、手杖使用；措施示例：卫生间防滑与扶手、用药观察（体位性低血压/低血糖）、夜间照明与呼叫器、跌倒预警手环、家属宣教。

### 试题二：为跌倒的老年人进行急救处理（12 分钟，100 分）

**案例（模板，可替换）**：养老机构食堂走廊，李奶奶，82 岁，起身取餐时不慎跌倒，坐倒在地，右髋部疼痛，诉不能活动右下肢。请进行应急处置。

**评分表（官方分值，S12 原文拆项）**

| 板块 | 评分条目 | 分值 |
|---|---|---|
| 职业规范/准备 | M1 简述识别老人跌倒的初步情况，并做出正确应对（2 分）＋M2 着装、手卫生、用物（急救箱、夹板/固定带、记录单）齐全、环境准备（4 分） | 6（漏关键物品扣 0.5/项） |
| 沟通解释评估 | 问好称呼、核实身份、介绍处置过程、征询配合 | 15 |
| **M8 关键操作** | （1）**立即到达现场，判断老年人神志，询问有无不适，安抚情绪** | 6 |
| | （2）**让老年人保持跌倒后的姿势、减少活动** | 2 |
| | （3）初步评估老年人伤情：①有无头晕头痛、恶心、呕吐等；②摔伤部位、疼痛情况，有无出血、畸形、肿胀及功能障碍等；③必要时测量脉搏、呼吸、血压 | 15 |
| | （4）根据老年人身体情况，采用**科学、节力、安全**的方法协助老年人起身（本案例右髋剧痛应**就地制动**），安置至舒适安全体位 | 10 |
| | （5）**报告医生，遵医嘱给予处理**：①未受伤——密切观察意识、生命体征、皮肤等；②皮下出血、肿胀——嘱减少活动并冰袋冷敷，冷敷方法及时间正确，**避免冻伤**；③外伤出血——评估伤口、协助包扎，方法科学正确，**避免感染**；④**骨折——嘱减少活动，并进行肢体固定，请医生指导及处理** | 15 |
| | （6）处理过程中密切观察老年人情况，及时给予心理安抚 | 2 |
| 健康教育 | 跌倒原因分析＋预防要点（≥3 条） | 5 |
| 科技照护 | 跌倒预警设备报警解读、管理平台事件记录 | 5 |
| 安全防护 M11 | 同试题一 M11 四项 | 5 |
| 人文关怀 | 同试题一 M12 四项 | 5 |
| 记录 | 跌倒时间、地点、情境、评估结果、处置措施、报告与后续观察**不漏项** | 5 |
| J 综合评判 | 灵活机动、亲和力、责任心 | 4（+ 红线：违反法规标准零分） |

**本案例参考判读（整理推断）**：右髋疼痛＋不能活动下肢 → 高度怀疑髋部骨折 → 正确处置链：不搬动 → 安抚保暖 → 初步评估（髋部外观/活动/末梢血运）→ 报告医生 → 就地制动固定 → 记录上报 → 等待 120/专业转运。若"立即扶起"即触发 2 分项失分＋50 分量级重扣（对应扣分点总结第 1、2 条）。

### 对照校验：江苏题库（S13）"老年人跌倒的应对处理"十一步骤（M8 50 分，官方原文要点）

1. 判断意识，询问感觉、确认周围环境，安抚情绪（5 分）；
2. 评估心悸、头晕，检查脉搏（5 分）；
3. 评估面部表情、肢体活动灵活度、语言流利程度，排除意外伤害（5 分）；
4. 评估肢体活动能力、有无骨折/疼痛/擦伤/伤口/出血，确认安全（6 分）；
5. 情绪稳定且确认无肢体损伤后，指导肢体活动并给予心理支持（5 分）；
6. 协助取坐位或卧位并询问感觉，进行平衡功能评估（4 分）；
7. 询问跌倒原因、诱因，给予预防跌倒健康教育（8 分）；
8. 再次核对身体、感觉情况，询问是否需要进一步医疗检查（2 分）；
9. 取舒适体位，盖好盖被，支起床档，检查床挡安全（3 分）；
10. 整理、洗手（2 分）；
11. 记录：跌倒的原因、时间、地点、感觉及处理方法（5 分）。

【整理推断】两版评分表骨架一致（判断→评估→处置→健康教育→记录），命题时可将 S13 步骤拆入 S12 分值结构；"记录 5 分"与"健康教育 8 分"是江苏版特色，校内模拟考建议保留。
