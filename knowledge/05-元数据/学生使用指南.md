# 学生使用指南（智能体怎么用）

来源：本项目交付配套（v0.4 新增；面向智慧健康养老服务与管理专业学生）
维度：元数据（用户指南）
关键词：学生使用指南、提问技巧、四栏卡片、追问、澄清

## 核心内容摘要

本指南告诉你怎么用"岗课赛证融通智能体"：它只答"老年人跌倒的预防与应急处置"这一个技能点，但会把你的问题拆成**岗（岗位标准）、课（课程内容）、赛（技能大赛）、证（证书考核）**四个维度回答，每栏都标来源、可核对。

## 详细内容

### 一、直接问（推荐问法示例）

| 你想解决的 | 这样问 |
|---|---|
| 搞清楚一个技能点 | "老年人跌倒的预防与应急处置" / "老人摔倒了怎么办" |
| 备考（证书） | "考证考不考跌倒？实操怎么考？" / "Morse 量表怎么判风险等级？" |
| 备赛（大赛） | "大赛跌倒环节怎么扣分？" / "跌倒应急处置 12 分钟怎么分配？" |
| 学课 | "实训任务单考核考什么？评分表怎么用？" |

### 二、会看到什么

- **四栏卡片**：【岗】【课】【赛】【证】各一栏，顺序固定。每栏第一行是一句话结论，后面是 ①②③ 细节，栏末有（来源：文档名（路径））。
- **澄清提问**：如果你只输"跌倒"这类词，它会先问你到底想问哪块（应急处置/预防/都要/备考），选一个即可；不选就默认全讲。
- **空栏**：某维度没有材料时会明说"该维度材料待补充"，**不会编**。
- **免责声明**：首次回答末尾会提醒"仅供学习备考，真实跌倒请立即找现场医务人员或拨 120"。

### 三、追问技巧

- "展开【赛】" → 只把赛那一栏讲深（其他栏略过）。
- "第 3 条扣分点具体是什么操作？" → 沿上下文继续问即可。
- "用 JSON 输出" → 得到机器可读的结构化结果（给老师/导出用）。

### 四、它不做什么（别浪费时间试）

- 不答其他技能点（噎食、失智照护等会明确说"超出范围"，建议问任课老师）。
- 不能改文件、不能执行命令（学生端是只读工作台）。
- 不代替临床决策：真实场景按教材与老师教的操作为准。

### 五、材料从哪来

智能体引用的所有材料都在工作区 `01-岗/ 02-课/ 03-赛/ 04-证/` 四个目录里，来源标注里的路径就是文件位置，点开可核对原文。带"校本草稿/模板待填"标注的是学校内部待替换材料，带"模拟编写"的题是模拟题（非真题）。
