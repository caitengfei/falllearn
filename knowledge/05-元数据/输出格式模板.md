# 输出格式模板（岗课赛证四栏卡片）

来源：SPEC.md 第二部分 2.1、第六部分 6.2（排版经 v0.4 学生体验修订：结论先行、来源含文档名、空维度友好话术）
维度：元数据（输出排版规范）
关键词：四栏卡片、输出格式、来源标注、结论先行、JSON 模式

## 核心内容摘要

定义智能体回答的标准排版：默认输出为 Markdown 四栏卡片（【岗】【课】【赛】【证】各一栏，**每栏先一句结论**，再编号展开，栏末标注"（来源：文档名（相对路径））"）；可选 JSON 程序化模式（P2，供后续前端/导出系统使用）。

## 详细内容

### 默认模式：Markdown 四栏卡片

```markdown
【岗】临床岗位标准
<一句结论：岗位标准对本技能点要求什么>
① 标准要求：<对应国家职业技能标准条款>
② 处置流程：评估→不急于搬动→呼叫支援→按预案处置→记录上报
③ 安全提示：<关键安全要点>
（来源：养老护理员国家职业技能标准-风险应对（01-岗/养老护理员国家职业技能标准-风险应对.md））

【课】课程知识点映射
<一句结论：对应哪个课程任务、学生要练到什么程度>
① 对应课程：《老年人安全照护与急救技术》项目二"跌倒的防护与急救"任务3
② 核心知识点：Morse 量表 / 五步法 / 骨折就地制动 / 记录上报
③ 推荐学习资源：实训任务单-跌倒应急处置（100 分评分表＋3 情景）
（来源：知识点梳理（02-课/知识点梳理.md）、实训任务单-跌倒应急处置（02-课/实训任务单-跌倒应急处置.md））

【赛】技能大赛对标
<一句结论：大赛哪里考跌倒、怎么给分>
① 相关赛项：健康养老照护（GZ063）"安全防护与应急处置"模块
② 关键给分点：风险识别、节力起身、分型处理、记录不漏项
③ 常见扣分操作：未先评估意识直接搬动、延误呼救……（3—5 条）
（来源：评分标准-安全防护与应急处置模块（03-赛/评分标准-安全防护与应急处置模块.md））

【证】证书考核对接
<一句结论：哪个证书考、考什么形式>
① 证书：养老护理员（职业技能等级证书，理论 60 分合格）
② 考核方式：实操"跌倒预防与应急处理"（12 分钟限时）
③ 模拟真题：<1—2 道，含答案要点，标注模拟编写>
（来源：实操考核试题-跌倒预防与应急处理（04-证/实操考核试题-跌倒预防与应急处理.md））
```

**排版规则**

1. 四栏顺序固定为 岗→课→赛→证，不可调换；栏名加粗。
2. **每栏第一行必须是一句结论**（该维度要求学生知道/做到什么），再用 ①②③ 编号展开细节。
3. 每栏内容控制在学生 2 分钟内可读完；追问某栏时可展开该栏。
4. 来源标注格式：**（来源：文档名（相对路径））**——文档名便于学生核对内容，相对路径便于定位文件；一份文档一次，引用多份用顿号分隔。
5. 某维度检索无内容时，该栏只输出一行：`该维度材料待补充（详见 05-元数据/更新日志"待补充清单"）`，不得编造。
6. 模拟真题必须来自 04-证/ 文档并保留"模拟编写"标注；题库中没有的题型不虚构真题，可说明"该题型题库待补充"。
7. 首次四栏回答末尾附一行："本回答仅供学习备考；若你正面对真实跌倒的老人，请立即联系现场医务人员或拨打 120。"
8. 学生使用指南见 `05-元数据/学生使用指南.md`（该文件位于工作区内，可用 read 读取；不得引用其路径作为"来源"）。

### 可选模式：JSON 程序化输出（P2）

当用户明确要求"以 JSON 输出"时，输出如下结构（不附加任何额外说明文字）：

```json
{
  "岗": { "结论": "...", "标准要求": "...", "处置流程": ["步骤1", "..."], "安全提示": "...", "来源": "..." },
  "课": { "结论": "...", "对应课程": "...", "章节": "...", "核心知识点": ["..."], "推荐资源": "...", "来源": "..." },
  "赛": { "结论": "...", "相关赛项": "...", "关键给分点": ["..."], "常见扣分点": ["..."], "来源": "..." },
  "证": { "结论": "...", "证书名称": "...", "考核方式": "...", "模拟真题": ["..."], "来源": "..." }
}
```

- "来源" 字段格式为"文档名（相对路径）"（多份用顿号分隔）；该维度无材料时，整栏值为 `"该维度材料待补充"`。
- 必须为可被 `JSON.parse` 直接解析的合法 JSON，禁止注释、禁止尾逗号。

## 可直接引用的片段

> 四栏顺序固定为 岗→课→赛→证，不可调换；每栏第一行是一句结论，栏末以"（来源：文档名（相对路径））"标注出处。

> 某一维度检索无内容时，输出"该维度材料待补充（详见 05-元数据/更新日志'待补充清单'）"，不得编造。
