# 回家操作指南 · 康养智行上传 GitHub

> 给：项目 owner。U 盘里这个压缩包 = 完整源码 + 全部 git 存档（.git 已包含）。
> 家里电脑要求：Windows + 能上网（能打开 github.com）。**不需要**会编程。

## 第 0 步：把包从 U 盘解压到本地磁盘（1 分钟）

把压缩包**右键 → 全部提取**到比如 `D:\FallLearn`（或 C 盘任何位置）。
⚠️ 解压后文件夹里应该能看到一个**隐藏的 .git 文件夹**（没有它 git 存档就丢了！
验证方法：文件管理器顶部"查看 → 显示 → 隐藏的项目"勾上，看 D:\FallLearn\.git 是否存在）。

## 第 1 步：注册 / 确认 GitHub 账号（5 分钟）

1. 打开 https://github.com → 右上角 **Sign up**
2. 用邮箱注册（建议用真实姓名 + 学校邮箱，比赛材料更规范）
3. 注册完按提示登录即可

## 第 2 步：用 GitHub Desktop 上传（推荐，全程点鼠标，5 分钟）

1. 打开 https://desktop.github.com → 下载 Windows 版 → 安装（一路下一步）
2. 打开 GitHub Desktop → 左侧 **Sign in to GitHub.com** → 输入账号密码登录
3. 顶部菜单 **File → Add Local Repository…** → 选择 `D:\FallLearn`（第 0 步解压的文件夹）→ **Add**
4. 右侧会出现 **Publish repository** 面板：
   - Repository name：`falllearn`（小写即可）
   - Description：可填「智慧健康养老·岗课赛证融通学生平台」
   - **Visibility 选 Public**（公开，评委才能访问；如学校要求私有就选 Private）
5. 点 **Publish Repository** → 等进度条走完 ✅
6. 复制页面上的仓库地址（形如 `https://github.com/你的用户名/falllearn`）——**这个链接就是交给学校/比赛的"源码地址"**

## 第 2' 步（备选）：不会用桌面版就命令行，共 3 条命令

1. 先装 Git：https://git-scm.com/download/win 一路下一步
2. 按 Win+R 输入 `cmd` 回车，粘贴：
   ```
   cd /d D:\FallLearn
   git remote add origin https://github.com/你的用户名/falllearn.git
   git push -u origin main
   ```
   （第一行里 `你的用户名` 换成你 GitHub 主页用户名；要先在网页上按第 2 步 3~5 先建好同名仓库，且**不要**勾选 Add README）
3. 第一条命令没反应=正常；第三条命令会**弹出浏览器**让你登录 GitHub 授权 → 点同意即可
4. 看到 `* [new branch] main -> main` 就成功了

## 常见问题

| 症状 | 解决 |
|---|---|
| 上传很慢/一直转 | 国内访问 GitHub 不稳：换手机热点重试，或改用下面的 Gitee 方案 |
| 提示 "not a git repository" | 解压时丢了 .git 隐藏文件夹 → 重新解压（确认第 0 步的验证） |
| 提示 remote 已存在 | 把 `git remote add` 换成 `git remote set-url origin 地址` 再 push |
| 杀毒软件报毒（git 可执行文件） | 误报，选"仍要保留" |

## Gitee 备用方案（国内快，同样能交作业）

如果 GitHub 始终连不上：
1. 注册 https://gitee.com（手机号即可）
2. 网页新建仓库 `falllearn`（公开，不勾 README）
3. cmd 里把第 2' 步的地址换成 `https://gitee.com/你的用户名/falllearn.git` 再 push
4. 两个平台地址都可以，交哪个以学校通知为准（一般 GitHub 为主、Gitee 为备）
