# 真实班级试用计划（2026-10-01 ~ 10-04）

> 目的：为申报「应用成效与推广价值（20 分）」取得**匿名化的真实使用证据**。
> 红线：收集任何学生信息只用于匿名统计；问卷不收集可识别个人的信息（学号平台内闭环，导出时映射为 1 号/2 号…）。

## 一、准备（10-01 上午，约 30 分钟）

1. **批量建号**：教师 T2026 登录 → 账号管理 →「批量发号」
   - 学号前缀建议 `S20261`（S2026101…S20261NN，NN=人数）
   - 数量 = 班级人数，初始密码 123456，姓名模板可留默认（**正式试用时建议按名单替换**，或让学生登录后自行核对；若不想收真实姓名，保持「同学N」即可）
   - 把「学号 + 初始密码 123456」发给学生（可打印一张账号表）
2. **布置 2 个任务**（考试管理 → 新建练习，按知识点选簇）：
   - 任务 A：五步处置 + 骨折识别（10 题，限时 15 分钟）—— 周三前完成
   - 任务 B：Morse评估 + 环境防控（10 题，不限时）—— 周日（10-04）前完成
3. **告知学生**（一段话模板）：
   > 本周课程试用「防跌学堂」AI 学习平台：登录链接 ___，学号+密码见账号表。请完成老师布置的 2 组练习，平时有空可以问问 AI 老师、看看知识库。10 月 4 日填一份 3 分钟的小问卷。
4. 提醒：首次登录会出现「演示体验路径」引导卡，跟着走 6 步即可上手。

## 二、试用期间（10-01 ~ 10-04）

- 教师端**每天看一眼**：数据总览（活跃/练习）+ 培训情况统计（完成情况）；对未开始的学生催一下。
- 学生卡壳时统一引导：顶部「？」= 演示路径；顶部搜索框 = 问 AI 老师。
- 如遇故障：教师 T2026 登录「演示数据重置」不可用（会清数据，**试用期间禁用**）；直接联系开发者，服务器数据随时可备份（falllearn.db 单文件）。

## 三、问卷（10-04 课中，3 分钟，纸质或在线表格均可）

1. 这周你在平台上完成了 ____ 组练习（选：0 / 1 / 2 / 2 以上）
2. 你觉得 AI 老师的回答**准确、有出处**，对理解帮助大吗？（很有帮助 / 有帮助 / 一般 / 没帮助）
3. 错题本的「间隔复习」提醒有用吗？（有用 / 一般 / 没用）
4. 你最喜欢平台哪个功能？（AI 问答 / 知识库 / 练习判分 / 学习报告 / 其他___）
5. 一个建议或不满：____

## 四、数据收集与匿名化（10-04 课后，约 40 分钟）

1. 教师端导出/截图：
   - 数据总览（活跃/练习/AI 问答/学时）
   - 培训情况统计（2 个任务完成率 + 平均分）
   - 班级错题分析（TOP10 + 知识点正确率）
   - 排行榜（积分/掌握度 tab 各一张，**提交前抹去姓名只留学号后 3 位**）
2. 问卷回收 → 统计：
   - Q1 分布、Q2 四档占比、Q3 三档占比、Q4 词频、Q5 摘录 3–5 条典型建议（匿名）
3. 填 `docs/rubric_selfcheck.md` 第四节（应用成效）：真实数字替换 ⚠️ 待补 项。
4. **演示数据保护**：S2026001/T2026 的演示剧情数据不受影响（不同账号），10-08 冻结前最后一次恢复 v3 初始态（保留真实试用账号与其数据作为成效佐证 —— 若担心评委误操作，可在冻结时只保留统计截图、清空试用账号学习痕迹）。

## 五、风险预案

- 学生少于 10 人参与：成效口径改为「课程小范围试用（N 人）」，强调可推广性，不夸大。
- 服务器故障：`systemctl status falllearn` 查看；DB 备份 `scp /opt/falllearn/backend/falllearn.db` 到本地。
- 时间不够（10-04 拿不到数据）：申报书成效节写「已开展课程内试用（数据见测试链接教师端实时统计）」，用平台实时数据代替问卷。
