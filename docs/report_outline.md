## 5 分钟提问预案（高频问题 + 回答要点）

**Q1 这是套壳 ChatGPT 吗？**
不是。AI 通道只是『推理执行器』：四栏结构化解析、出处标注（每栏回链知识库文件）、流式管线、学习分析提示词工程、掌握度更新——都是自研管线，代码开源可查（GitHub 提交历史）。

**Q2 题库哪来的？1632 题？**
真实课程资源：世赛/省赛规程考点、三证考核标准、护理理论题库（来源逐题标注，如『江苏2023养老护理员技能竞赛理论题库』），并按六簇知识点人工标注。

**Q3 数据隐私怎么保证？**
本地部署 + SQLite，业务数据不出服务器；AI 问答只把题目文本发给 LLM 通道（无学生身份信息）；学生账号全部虚构，无真实个人信息；密钥每服务器自动生成不入库不入 Git。

**Q4 和现有教务系统/智慧课堂的区别？**
我们不替代教务系统，而是做『学科纵深』：现有系统管成绩流程，我们管『学什么、怎么问、错在哪、下一步练什么』的学科智能闭环，且岗课赛证内容是可替换的学科资产。
同样，我们也不替代市面通用在线学习平台（企业培训类 SaaS）：它们解决『课程与培训流程管理』，我们解决『一个技能点的岗课赛证四维学与教闭环』——答案逐栏可溯源、掌握度驱动教与学；且架构可扩展：知识库按四维编目，换一套课程资料即可迁移到噎食急救、失智照护等其他技能点。一句话：通用平台是『容器』，我们是懂这门专业的『智能教练』。

**Q5 流式输出技术上怎么做的？**
后端 SSE：LLM 直连通道逐块解析，经会话队列推给前端 fetch 流式读取，15 秒心跳保活；断流自动回落到轮询。前端用 Vue 响应式代理增量渲染。

**Q6 掌握度怎么算的？**
按知识点簇维护 EMA（指数移动平均）掌握度 0–100：答对上升、答错下降，权重随复习次数衰减；驱动练习组卷、首页薄弱提醒、报告分布图、教师端条形图，全平台同一份数据。
