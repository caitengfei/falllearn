## 三、现场加演：学生当场注册（30 秒）

1. 教师端 → **账号管理** → 绿色卡片「🎟 邀请码 · 学生自助加入」→ 展开 → 点「生成邀请码」；
2. 点「复制链接」（或出示提前生成的注册二维码）→ 投屏；
3. 学生手机扫码 → 填**昵称 + 自设密码** → 点"注册并进入" → 直接进首页。

> 一句话说明隐私："注册不采集手机号、邮箱、身份证和学号，学号由平台自动分配。"

## 六、评委追问速答（3 条高频）

- **是不是套壳大模型？** 不是。AI 只是执行器：可溯源解析、逐栏出处回链、SSE 流式管线、知识点掌握度模型都是自研；GitHub 提交历史可查。
- **学生数据隐私怎么保证？** 只采集昵称与自设密码；不采集手机号/邮箱/身份证/学号；成绩与错题只存本地服务器；账号可物理删除。
- **与智慧课堂/教务系统的关系？** 不替代教务系统，做学科纵深：管"学什么、怎么问、错在哪、下一步练什么"。
