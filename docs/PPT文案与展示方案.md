# PPT 文案与展示方案（康养智行 · 职业院校赛道）

> 用途：现场汇报 PPT 与展示视频的**成品文案**，可逐页复制；与 `report_outline.md`（10 分钟口播）、`demo_video_script.md`（视频分镜）配套。
> 匿名红线：所有页面**不得出现姓名、学校、院系、医院**；演示账号均为虚构账号。

## P1 封面

- 主标题：**康养智行**
- 副标题：**智慧养老“岗课赛证”融通智能体**
- 一行说明（小字）：以跌倒预防与应急处置为首发场景 · 知识库按岗课赛证四维编目 · 架构支持向全技能照护赛训扩展
- Slogan（右下）：**智护银龄，行稳致远**
- 页脚：职业院校赛道 ｜ 测试链接（二维码同页给出）

## P2 为什么做（痛点页，命中“特色 20 分”）

标题：**一个技能点，四套资料，三种困境**

- 岗课赛证知识分散：岗位标准、课程资源、竞赛要求、证书考核各自成册，学生手工对照
- 通用 AI 回答无出处：与竞赛评分口径、临床规程不一致，甚至出现“未制动即搬动”等错误引导
- 教学反馈滞后：教师“下节课讲什么”依赖经验

## P3 是什么（定位页）

标题：**不是通用问答，是懂这门专业的智能教练**

- 46 份真实文档知识库（岗 10／课 7／赛 13／证 11／元数据 5），均可全文检索读原文
- 1363 题结构化题库，六簇知识点贯穿问答—练习—错题—报告全链路
- 三级分权：学生 / 教师 / 管理员，全端点 JWT 鉴权

## P4 智能化（命中“智能 25 分”）

标题：**AI 的四栏结构：每个答案都可溯源**

- 四栏问答【岗】【课】【赛】【证】，逐栏标注原文出处；无材料的维度提示“待补充”
- 流式输出：首块 0.5 秒，全文约 4 秒
- 掌握度模型（EMA）驱动：组卷、薄弱提醒、学习报告、教师决策同一份数据
- 教师端 AI：出题、判卷、班级错题分析（高频 TOP10 + 知识点正确率）

## P5 教学闭环（命中“融合 25 分”）

标题：**30 秒走完一个教学闭环**

- 布置 → 练习（限时 + 积分）→ 秒级判分 → 错题自动入本（次日→第 3 天间隔复习，连对 2 次掌握）
- 教师侧：班级错题分析 → 下节课讲什么 → 精准再布置
- 场景：课前预习 / 实训答疑 / 竞赛集训（12 分钟模拟考）/ 证书备考

## P6 成效（命中“成效 20 分”）

标题：**实测数据（可复跑）**

- 首屏 FCP **220ms**、传输 **65KB**（gzip 压缩率 61%）；16 并发压测零错误
- 6 视口 × 8 页零横向溢出；WCAG AA 对比度；移动端触控合规
- 两轮安全加固：依赖漏洞清零、安全验收 26 项全过
- （试用班级数据待填：活跃学生 X 人 / 练习 X 组 / 问答 X 次 / 满意度 X）

## P7 可扩展（**视觉化三行，不要用长句**）

标题：**首发场景做深，架构留出全技能照护赛训的扩展位**

```
🎯 首发场景：跌倒预防与应急处置
📚 四维编目：岗 · 课 · 赛 · 证
🚀 扩展能力：架构支持向全技能照护赛训扩展
```

注脚一句：知识库与题库均为结构化文本，换一套课程资料即可迁移到噎食急救、失智照护等技能点。

## P8 规范与安全（命中“材料 10 分”）

- 匿名合规：无姓名/学校/院系/医院；账号虚构；数据脱敏
- 安全：CSP、登录节流、越权/刷分/XSS/SSRF 防护、依赖漏洞清零（报告可查）
- 原创性：Git 提交历史 + 10 套验收脚本 + 两轮安全报告 + 专利/软著材料（见佐证包）

## P9 结语

- 主句：**让每一个养老照护技能点，都有一个可溯源、可训练、可评价的智能体**
- Slogan 收束：智护银龄，行稳致远
