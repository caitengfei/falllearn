# 服务器部署说明

把本仓库（或 U 盘交付包解压后的目录）上传到任意 Linux 云服务器，3 步上线：

```bash
# 1) 上传（在本机执行，IP 换成你的服务器公网 IP）
scp -r FallLearn root@<服务器IP>:/opt/

# 2) 登录服务器
ssh root@<服务器IP>

# 3) 一键部署
cd /opt/FallLearn && bash deploy/deploy.sh 8010
```

之后浏览器打开 `http://<服务器IP>:8010` 即可访问（学生端 + 管理后台同端口）。

## 注意事项

1. **无需域名、无需 ICP 备案**：直接用「IP:端口」访问，备案只在用域名 + 80/443 端口时需要（周期数周，学生项目不建议）。
2. **云安全组**：阿里云/腾讯云控制台 → 安全组 → 入方向添加 TCP 8010 放行（否则公网访问超时）。
3. **演示账号**：学生 S2026001 / S2026002 / S2026003，教师 T2026，密码均 123456；演示结束可进「数据总览」点「演示数据重置」恢复基线。
4. **AI 功能**：需另配 DSH 智能体服务（见根 README「AI 功能」节）；无 DSH 时其余功能完全可用。
5. **升级**：重新 `scp -r` 覆盖代码后 `systemctl restart falllearn`；数据库文件（`backend/falllearn.db`）不在仓库内，不会被覆盖。
